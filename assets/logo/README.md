# Logo

O logo é a palavra "tone" em Crimson Pro Medium (500), minúscula, com -0,04em entre as letras. Todos os arquivos estão em contorno: nenhum precisa da fonte.

| Peça | Arquivos | Uso |
|---|---|---|
| Palavra (`wordmark`) | `tone-wordmark-<cor>` | O logo |
| Marca (`mark`) | `tone-mark-<cor>` | O "t" sozinho, onde a palavra não cabe |
| Ícone (`icon`) | `tone-icon-<cor>-on-<fundo>` | O "t" num quadrado: ícone de app, favicon, avatar |

Cores: vinho `#340b10`, coral `#e26b5c`, blush `#fff4f2`, preto e branco. As versões `-on-<fundo>` já trazem o fundo.

`svg/` tem os vetores (é o que vai no pacote, em `@toneorg/design/logo/<arquivo>.svg`); `png/` tem as exportações em 512, 1024 e 2048 px.
